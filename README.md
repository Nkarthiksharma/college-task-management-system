## ✨ Features

### 🔐 Authentication & Authorization
- Secure Login System
- Role-Based Access Control
- Session Management

---

### 👨‍💼 Principal Module
- Create Tasks for any department
- Assign Tasks to Multiple Faculty Members
- Add Faculty to Existing Tasks
- Remove Faculty from Existing Tasks
- Upload Multiple Attachments
- Monitor Task Progress
- View Pending & Completed Tasks
- Filter Tasks by Department

---

### 👨‍🏫 HOD Module
- Create Department-Specific Tasks
- Assign Tasks to Faculty within the Department
- Add Faculty to Existing Department Tasks
- Remove Faculty from Existing Department Tasks
- Monitor Department Task Progress
- View Pending & Completed Department Tasks

---

### 👩‍🏫 Faculty Module
- View Assigned Tasks
- Update Task Status
- Submit Remarks/Comments
- View Task Attachments

---

### 📋 Task Management
- Create Tasks
- Assign One Task to Multiple Faculty Members
- Add/Remove Faculty from Existing Tasks
- Due Date Management
- Task Status Tracking
- Task Description with Rich Text Editor
- Multiple File Attachments

---

### 📎 Attachment Management
- Upload Multiple Files
- Store Attachments Securely
- Download/View Attachments

---

### 📧 Email Notifications
- Automatic Email Notification when Tasks are Assigned

---

### 📊 Dashboard
- Principal Dashboard
- HOD Dashboard
- Faculty Dashboard
- Department-wise Task Monitoring
- Pending & Completed Task Statistics

---

### 🛠 Additional Features
- Department Filtering
- Searchable Faculty Selection (Select2)

- Session Management
- MySQL Database Integration
- Responsive User Interface
